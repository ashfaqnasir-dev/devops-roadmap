# Docker WSL 2 Integration — Complete How-To

> Docker ko WSL (Ubuntu) se connect karne ka poora tareeqa.

## Background

Docker Desktop Windows par install hota hai. WSL (Ubuntu) se `docker` commands chalane ke liye **WSL Integration** enable karna parta hai. Yeh guide rozana check karne ke liye hai.

## Prerequisites

- Windows 10/11
- WSL 2 installed
- Ubuntu WSL distro
- Docker Desktop installed (Windows)
- Virtualization enabled in BIOS
